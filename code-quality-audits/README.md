# Historical reviews

The dated review reports and scanner artifacts formerly stored here are historical
snapshots. They are preserved in [the repository history before the public-readiness
cleanup](https://github.com/Ponchia/bronto-ui/tree/7b7463af1b878e42230d196fd2bf234959b6a5ec/code-quality-audits).
They may refer to removed APIs, earlier architecture, or unresolved proposals; they
are not current instructions or a claim that every historical finding was resolved.

For the maintained code and documentation map, use
[docs/repository-map.md](../docs/repository-map.md). Current contracts and decisions
live in [the documentation](../docs/README.md), and the regression checks live in
[scripts/](../scripts/) and [test/](../test/). Keep future raw scanner output and
transient review prompts outside the tracked source tree. Record lasting decisions
in the relevant maintained document or an ADR, with a focused regression test when
behavior changes.
